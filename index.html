🔗 專案綁定管理器

此瀏覽器尚未綁定 Firebase 專案。請輸入您的 Site ID 與 Firebase Config，完成後頁面將自動重新整理並啟動。

📋 步驟說明

  1. 前往 Firebase Console → 專案設定 → 一般
  2. 在「您的應用程式」中找到網頁應用，複製 firebaseConfig 物件
  3. 自訂一個唯一的 Site ID（英數字，例如 litdb_alice），用於隔離不同部署

⚠️ 綁定資訊儲存在 此瀏覽器的 localStorage，不會上傳到任何伺服器。不同電腦需分別綁定。
